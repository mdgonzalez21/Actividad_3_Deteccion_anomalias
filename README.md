# Detección de Anomalías — Aprendizaje No Supervisado

Repositorio correspondiente a la **Actividad III** de la asignatura *Machine Learning No Supervisado* (Máster en Inteligencia Artificial - UNIR). El proyecto implementa algoritmos y técnicas de análisis no supervisado para la identificación y evaluación de anomalías sobre conjuntos de datos estructurados.
